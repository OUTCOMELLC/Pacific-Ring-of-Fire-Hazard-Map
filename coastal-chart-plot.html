Chart plot is schematic — a coordinate graticule, not a navigation chart; positions are real station coordinates. Wave height is a model value (Open-Meteo Marine) sampled at each buoy's location, since NDBC's raw feeds block browser access. Japan/Okinawa stations (◇) are approximate NOWPHAS/JMA positions. Live data needs a connection — hosted over https:// it populates; offline you'll still see the grid & positions.
